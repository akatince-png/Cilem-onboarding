# Originale (nicht im Git)

Dieser Ordner ist absichtlich leer. Rohfotos und -videos liegen im **Cloud-Speicher der Kundin**
(z. B. Google Drive-Ordner „Website – Originale“ im Google-Konto der Kundin) und werden nur
zum Bearbeiten lokal hierher kopiert:

```
originals/images/   Fotos (JPG, PNG, TIFF, HEIC)
originals/videos/   Videos (MOV, MP4)
```

Alles hier außer dieser Datei wird von `.gitignore` ausgeschlossen.
