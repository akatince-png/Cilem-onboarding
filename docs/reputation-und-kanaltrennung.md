# Reputation & Trennung geschäftlich / privat

## Prinzip
Die geschäftliche Präsenz wird so stark und konsistent aufgebaut, dass sie bei Namens- und
Fachsuchen die ersten Ergebnisse belegt. Private Profile bleiben unberührt und werden nicht verlinkt.

## Konkrete Regeln
1. **Eigene Identität für alles Geschäftliche:** geschäftliche E-Mail auf eigener Domain als Login für
   Google, LinkedIn, Formular-Dienst – keine private Gmail-/Social-Login-Verknüpfung.
2. **Einheitlicher Name (NAP-Konsistenz):** Name, Ort, Kontakt überall identisch (Website, GBP, LinkedIn, Verbände).
   Einzige Quelle: `website/src/config/site.ts`.
3. **Keine privaten Daten veröffentlichen:** keine Privatadresse (Servicegebiet statt Adresse im GBP;
   Geschäfts-/Virtual-Office-Adresse für die Rechtsseite), keine private Handynummer, keine Fotos mit Standortdaten.
4. **`sameAs` nur für geschäftliche Profile** (LinkedIn, Verbandsverzeichnisse). So verknüpft Google
   die richtigen Profile mit der Person.
5. **Starke eigene Kanäle**, die bei Namenssuche ranken: Website, Google Business Profile, LinkedIn,
   Verzeichniseinträge (CIOL/ITI/NRPSI Directory, sofern Mitglied), ggf. Fachartikel.
6. **Private Profile (Empfehlung an die Kundin, wertschätzend formuliert):** Sichtbarkeit überprüfen und
   Namen/Profilbild so wählen, dass sie nicht mit der Fachmarke verwechselt werden – eine Entscheidung,
   die allein bei ihr liegt.

## Monitoring
Monatlich Inkognito-Suche nach Name, „Name interpreter“, „Name London“ – Ergebnisse im Report festhalten.
